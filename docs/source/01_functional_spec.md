# Функциональное ТЗ приложения СТО

## Назначение

Приложение предназначено для внутренней работы сотрудников СТО: механиков, мастеров, приёмщиков и администраторов. Основная задача системы: вести заказ-наряд, фиксировать состояние автомобиля, прикреплять фото и файлы, оформлять диагностику, добавлять рекомендации и получать итоговую сводку по работам и стоимости.

## Основные роли

- Механик: заполняет акт осмотра, диагностику, прикрепляет фото, пишет рекомендации.
- Мастер/приёмщик: создаёт заказ-наряд, проверяет данные клиента и автомобиля, согласует рекомендации.
- Администратор: управляет пользователями, ролями, справочниками и доступами.

## Главные сущности

- Пользователь.
- Автомобиль.
- Заказ-наряд.
- Акт осмотра автомобиля.
- Диагностика ходовой, тормозов и трансмиссии.
- Рекомендации.
- Фото и файлы.
- Итоговая сводка.

## Общий рабочий процесс

1. Сотрудник создаёт или выбирает заказ-наряд.
2. Если автомобиль отсутствует, сотрудник заполняет данные автомобиля.
3. Сотрудник открывает акт осмотра и проходит форму по секциям.
4. Сотрудник открывает диагностику и заполняет категории: ходовая спереди, ходовая сзади, тормоза, стояночный тормоз, трансмиссия, итоги.
5. Сотрудник прикрепляет фото, документы или видео к заказу.
6. Сотрудник добавляет рекомендации с ценой запчастей и работ.
7. Мастер смотрит итоговую сводку и использует её для согласования с клиентом.

## Акт осмотра автомобиля

Акт осмотра хранится как структурированный JSON. Форма должна строиться по конфигурации, а не быть жёстко зашитой в интерфейс. Это позволит менять состав вопросов без постоянных изменений схемы БД.

## Статусы визуального осмотра

```python
INSPECTION_CONDITION_OPTIONS = [
    "ok",
    "attention",
    "urgent",
]
```

Значения:

- `ok`: внешне в порядке.
- `attention`: рекомендуется принять меры.
- `urgent`: требуются срочные меры.

## Типы полей акта осмотра

- `text`: обычный однострочный текст.
- `text_multiline`: многострочный комментарий.
- `number`: числовое поле.
- `choice`: выбор одного значения из списка `options`.
- `condition3`: выбор одного статуса из `ok`, `attention`, `urgent`.

## Секции акта осмотра

### Общие данные

- `order_number`: № заказ-наряда, тип `text`.
- `customer_name`: ФИО клиента, тип `text`.
- `customer_phone`: телефон клиента, тип `text`.
- `car_brand_model`: марка, модель автомобиля, тип `text`.
- `car_vin`: VIN, тип `text`.
- `car_plate`: гос. номер, тип `text`.
- `engine_spec`: объём/мощность двигателя, тип `text`.
- `car_year`: год выпуска, тип `number`.
- `car_mileage`: пробег, км, тип `number`.
- `visit_reason`: причина обращения, жалоба клиента, тип `text_multiline`.

### Секретки и запасные части

- `wheel_lock_present`: наличие секретки для колес, тип `choice`, варианты `да`, `нет`.
- `wheel_lock_location`: место хранения секретки для колес, тип `text`.
- `engine_immobilizer_present`: наличие секретки на запуск двигателя, тип `choice`, варианты `да`, `нет`.
- `spare_parts_handling`: заменённые запасные части, тип `choice`, варианты `возврат`, `утилизация`.

### Внешний осмотр: передняя светотехника

Все поля имеют тип `condition3`.

- `front_turn_signals`: указатель поворота, перед.
- `front_parking_drl`: габаритные огни / ДХО, перед.
- `low_beam`: ближний свет.
- `high_beam`: дальний свет.
- `front_fog_lights`: противотуманные фары, перед.

### Внешний осмотр: задняя светотехника

Все поля имеют тип `condition3`.

- `rear_turn_signals`: указатель поворота, зад.
- `rear_parking_lights`: габаритные огни, зад.
- `brake_lights`: стоп-сигналы.
- `rear_fog_lights`: противотуманные фонари, зад.
- `rear_tail_reverse_lights`: задние фонари / фонари заднего хода.

### Щётки и омыватели

Все поля имеют тип `condition3`.

- `front_wiper_blades`: щётки стеклоочистителей, передние.
- `rear_wiper_blades`: щётки стеклоочистителей, задние.
- `windshield_washer`: омыватели, лобовое стекло.
- `headlight_washer`: омыватели, фары.
- `rear_window_washer`: омыватели, заднее стекло.

### Подкапотное пространство

Для технических жидкостей используется подсказка: указать состояние и уровень, например `норма`, `низкий`, `высокий`, `есть течь`.

- `engine_oil`: масло в ДВС, тип `text`.
- `coolant`: охлаждающая жидкость, тип `text`.
- `gearbox_oil`: масло МКПП / АКПП, тип `text`.
- `drive_belts`: приводные ремни, тип `text`.
- `engine_operation`: работа ДВС, запуск, стабильность, шумы, тип `text_multiline`.
- `power_steering_fluid`: жидкость ГУР, тип `text`.
- `brake_fluid`: тормозная жидкость, тип `text`.
- `battery_charge`: АКБ, зарядка, тип `text`.
- `battery_replacement`: АКБ, замена, тип `text`.
- `battery_terminals`: АКБ, клеммы, тип `text`.
- `radiators_hoses`: радиаторы, патрубки, соединения, течи, тип `text_multiline`.

### Итоговые рекомендации по осмотру

- `inspection_recommendations`: рекомендации по результатам осмотра, тип `text_multiline`.
- `customer_source`: откуда клиент узнал о сервисе, тип `text`.

## Диагностика

Диагностика хранится как структурированный JSON. Для каждой позиции фиксируется статус. Если позиция неисправна или рекомендована к обслуживанию, при `has_price=True` дополнительно фиксируются цена запчастей и цена работ.

## Статусы диагностики

```python
DIAGNOSTIC_STATUS_OPTIONS = [
    "ok",
    "not_ok",
    "recommend_service",
]
```

Значения:

- `ok`: исправно.
- `not_ok`: не исправно.
- `recommend_service`: рекомендуется заменить или обслужить.

## Правила диагностики

- `side: "none"`: позиция без деления на левую/правую сторону.
- `side: "both"`: позиция проверяется отдельно слева и справа.
- `has_price: True`: при статусе не `ok` нужно спросить цену запчастей и работ.
- `has_price: False`: фиксируется только статус.

## Диагностика: ходовая часть спереди

- `front_shock_absorber`: амортизатор, перед, обе стороны, цена нужна.
- `front_shock_mount`: опора амортизатора, перед, обе стороны, цена нужна.
- `front_bumpstops_dust_covers`: пыльники / отбойники, перед, обе стороны, цена нужна.
- `front_spring`: пружина, перед, обе стороны, цена нужна.
- `front_upper_ball_joint`: шаровая опора верхняя, перед, обе стороны, цена нужна.
- `front_lower_ball_joint`: шаровая опора нижняя, перед, обе стороны, цена нужна.
- `front_hub_bearing`: подшипник ступицы, перед, обе стороны, цена нужна.
- `front_upper_arm_bushings`: сайлентблоки верхнего рычага, перед, обе стороны, цена нужна.
- `front_lower_arm_bushings`: сайлентблоки нижнего рычага, перед, обе стороны, цена нужна.
- `front_stabilizer_bar`: стабилизатор, перед, без стороны, цена нужна.
- `front_stabilizer_bushings`: втулки стабилизатора, перед, обе стороны, цена нужна.
- `front_stabilizer_links`: стойки стабилизатора, линки, перед, обе стороны, цена нужна.
- `front_stabilizer_link_bushings`: втулки стойки стабилизатора, линки, перед, обе стороны, цена нужна.
- `steering_rack`: рулевая рейка + течь, без стороны, цена нужна.
- `steering_tie_rods`: рулевые тяги, обе стороны, цена нужна.
- `steering_tie_rod_ends`: рулевые наконечники, обе стороны, цена нужна.
- `steering_column`: рулевая колонка, без стороны, цена не нужна.
- `steering_shaft_cardan`: рулевой кардан, без стороны, цена нужна.
- `front_subframe_beams`: подрамник / балки, перед, без стороны, цена нужна.

## Диагностика: тормозная система

Передняя ось:

- `front_brake_hose`: тормозной шланг, перед, обе стороны, цена нужна.
- `front_brake_disc`: тормозной диск, перед, обе стороны, цена нужна.
- `front_brake_pads`: тормозные колодки, перед, обе стороны, цена нужна.
- `front_brake_caliper`: суппорт, ревизия/смазка, перед, обе стороны, цена нужна.

Задняя ось:

- `rear_brake_hose`: тормозной шланг, зад, обе стороны, цена нужна.
- `rear_brake_disc_or_drum`: тормозной диск / барабан, зад, обе стороны, цена нужна.
- `rear_brake_pads`: тормозные колодки, зад, обе стороны, цена нужна.
- `rear_brake_caliper`: суппорт, ревизия/смазка, зад, обе стороны, цена нужна.

## Диагностика: стояночный тормоз

- `parking_brake_cable`: трос стояночного тормоза, без стороны, цена нужна.
- `parking_brake_shoes`: колодки стояночного тормоза, без стороны, цена нужна.

## Диагностика: трансмиссия

- `outer_cv_joint`: ШРУС наружный, обе стороны, цена нужна.
- `inner_cv_joint`: ШРУС внутренний, обе стороны, цена нужна.
- `outer_cv_boot`: пыльник ШРУС наружный, обе стороны, цена нужна.
- `inner_cv_boot`: пыльник ШРУС внутренний, обе стороны, цена нужна.
- `drive_shaft_seal`: сальник привода, обе стороны, цена нужна.

## Диагностика: итоги

- `other_recommendations`: прочие рекомендации по тормозам / ходовой, тип `text`.
- `alignment_comment`: развал-схождение, комментарий / рекомендации, тип `text`.
- `parts_total`: предварительная стоимость запчастей, тип `money`.
- `service_total`: предварительная стоимость услуг, тип `money`.
- `grand_total`: предварительная стоимость запчастей и услуг, тип `money`.
- `executor_name`: исполнитель, ФИО, тип `text`.

## Рекомендации

Рекомендация привязана к заказ-наряду и может быть связана с диагностикой.

Поля рекомендации:

- текст рекомендации;
- статус `suggested`, `approved`, `done`;
- цена запчастей;
- цена работ;
- автор создания;
- автор обновления;
- дата создания;
- дата обновления.

## Фото и файлы

К заказ-наряду можно прикреплять:

- фото;
- документы;
- видео.

Для приложения лучше использовать файловое хранилище: S3, MinIO или локальное хранилище. В БД нужно хранить ссылку на файл, тип, подпись, автора и дату создания.

## Итоговая сводка

Сводка должна показывать:

- номер заказ-наряда;
- данные автомобиля: марка/модель, VIN, гос. номер, пробег;
- проблемные пункты из акта осмотра;
- проблемные пункты из диагностики;
- список рекомендаций;
- сумму запчастей;
- сумму работ;
- общую сумму.
